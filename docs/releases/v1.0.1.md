# Moyu Sentinel 1.0.1

This release introduces built-in portable updates and several UI and reminder improvements.

### New

- Added an About page with version information, update management, and author details.
- Added automatic update checks against GitHub Releases.
- Portable updates download the official ZIP, verify its SHA-256 checksum, preserve `MoyuSentinel-data`, replace the application files after exit, and restart automatically.
- Added an optional popup sizing mode that follows the image aspect ratio. It is disabled by default.
- Added visible update progress and clear update status messages.

### Improved

- Popup windows are reasserted as topmost without stealing focus, preventing them from being covered by other windows.
- Edge overlays now rebuild when display resolution, topology, or DPI changes.
- The About entry is fixed at the right side of the top navigation.
- Top navigation remains fixed while only the content area scrolls.
- The reminder page title bar was removed, and the test button now shares the preview toolbar row.
- Preview sizing now uses decoded image dimensions so aspect-ratio changes synchronize immediately.

### Download

Download `MoyuSentinel-windows-x64.zip`, extract it, and run `MoyuSentinel.exe`. Keep the included DLL files and the `MoyuSentinel-data` directory. Microsoft Edge WebView2 Runtime is required.

Version 1.0.0 must be replaced manually once. Starting with 1.0.1, future releases can be installed from the About page.
