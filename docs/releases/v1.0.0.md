Moyu Sentinel 1.0.0 首个正式版本，面向 Windows 10/11 x64。

### 来人检测与组合提醒

- 本地摄像头人形检测，支持检测区域、人数、置信度和检测间隔设置。
- 边缘光、图片弹窗和自动操作可自由组合，边缘光与弹窗分别设置离开后的保留时间。
- 弹窗支持自定义大小、位置、边距和透明度，关闭按钮默认无背景；支持多显示器和关闭后暂停提醒。
- 检测到人时可自动打开指定网页或切换到已打开的应用窗口。

### 图库与编辑

- 批量导入最多 32 张图片，支持随机或顺序展示、排序、删除和 GIF 动图。
- 每张图片独立编辑标题和文案；内容为空时不显示文字区域。
- 左侧实时预览、右侧编辑，图片列表隐藏文件名并放大缩略图。
- 修复鼠标停在图片列表时滚动被阻断的问题，列表到达边界后可继续滚动编辑区。

### 共享与后台运行

- 支持局域网共享检测状态，多设备接收提醒；视频在本机处理。
- 支持托盘后台检测、暂停与恢复提醒，配置保存在便携目录。

### 下载使用

下载附件 `MoyuSentinel-windows-x64.zip`，解压后运行 `MoyuSentinel.exe`，保留同目录下的 DLL 文件。需要 Microsoft Edge WebView2 Runtime。

已有便携版可退出程序后替换程序文件，保留 `MoyuSentinel-data` 文件夹以继续使用原有配置和图片。
